# SPRX — Phase 10: Public Testnet

## Objective
Prepare and launch a controlled public SPRX testnet (`sprax-testnet-1`).

## Infrastructure & Features
* Validator nodes, RPC nodes, Seed nodes, Explorer, Faucet with rate limits and abuse prevention, Prometheus/Grafana monitoring, Alerting.
* Multi-node stress testing, Bug Bounty & responsible disclosure program.
* Strict label: **TESTNET — NO REAL VALUE**.
