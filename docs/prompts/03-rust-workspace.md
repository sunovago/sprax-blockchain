# SPRX — Phase 03: Rust Workspace

## Objective
Create the initial production-quality Rust workspace for SPRX according to the approved architecture and framework decision.

## Requirements
Create a Cargo workspace with clearly separated crates:
* sprax-core
* sprax-types
* sprax-crypto
* sprax-storage
* sprax-network
* sprax-consensus
* sprax-node
* sprax-cli

Implement:
* Cargo workspace & dependency management
* Rust toolchain, Formatting, Clippy
* Unit & integration test infrastructure
* Logging, error handling, configuration system
* CI pipeline
