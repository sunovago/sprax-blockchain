# SPRX — Phase 01: Architecture Master Prompt

## Project
**SPRX — Scalable Protocol for Real-world X**

SPRX is intended to become a globally usable blockchain protocol with a native cryptocurrency, wallet, explorer, validator network, smart-contract capabilities and real-world applications.

## Objective
Design the complete technical architecture of SPRX before writing production blockchain code.
This phase is architecture-only.

## Responsibilities
Analyze and define:
1. Overall blockchain architecture
2. Node architecture
3. Transaction architecture
4. Block architecture
5. State management
6. Consensus requirements
7. Validator architecture
8. P2P networking
9. Cryptography requirements
10. Storage architecture
11. RPC architecture
12. Indexer architecture
13. Wallet architecture
14. Explorer architecture
15. Smart-contract architecture
16. Governance architecture
17. Staking architecture
18. Upgrade architecture
