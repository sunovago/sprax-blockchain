# SPRX — Phase 08: Explorer and Indexer

## Objective
Build SPRX Explorer and the indexing infrastructure required to provide searchable blockchain data.

## Architecture
Blockchain → RPC → Indexer → Database → Explorer API → Web UI

## Features
* Home, Blocks, Transactions, Addresses, Validators, Staking, Network Stats, Search, Transaction Details, Block Details, Address Details.
* Indexing pipeline, consistency checks, rate limiting, pagination, responsive Web UI.
