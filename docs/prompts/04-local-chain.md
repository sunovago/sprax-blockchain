# SPRX — Phase 04: Local Blockchain

## Objective
Build the first functional local SPRX blockchain using the approved framework.

## Features
Implement:
* Genesis configuration
* Block structure & transaction structure
* Transaction validation & state management
* Block validation & chain initialization
* Local node startup & CLI commands
* Deterministic development configuration

## Testing
Create tests for valid/invalid transactions, invalid signatures, nonces, balances, amounts, replay prevention, and block validation.
