# SPRX — Phase 06: Consensus and Validators

## Objective
Implement and validate the approved consensus architecture.

## Rules
* Do NOT invent a new consensus algorithm.
* Use the mature consensus mechanism provided by the approved blockchain framework (CometBFT).

## Validator System
Implement:
* Validator registration, identity, status, set, stake, delegation, rewards, slashing, unbonding, lifecycle.

## Consensus Testing
* Honest validators, offline validators, restarted validators, network partition, invalid blocks, double spend attempts, recovery.
