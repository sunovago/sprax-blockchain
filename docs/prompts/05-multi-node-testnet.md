# SPRX — Phase 05: Multi-Node Network

## Objective
Run multiple SPRX nodes and verify network communication and synchronization.

## Initial Network
Create a local network containing at least 3 nodes (Node 1, Node 2, Node 3).

## Implement / Test
* Peer discovery, P2P communication, Block propagation, Transaction propagation
* State synchronization, Node restart recovery, Peer failure handling
* Network tests: node shutdown, restart, network partition, delayed/duplicate messages
* Docker deployment & monitoring metrics
